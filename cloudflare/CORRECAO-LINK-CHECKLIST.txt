CORREÇÃO DO LINK DE ACESSO AO CHECKLIST

O endereço /checklist/ID depende de um rewrite de rota. No ambiente atual hospedado em workers.dev, o roteamento pode entregar checklist.html sem preservar o trecho /ID na URL do navegador.

Para evitar perder o identificador, o botão ABRIR LINK do Admin agora gera o formato direto:
/checklist.html?id=15

O JavaScript da página lê o ID pelo parâmetro id da query string. Assim, o identificador permanece disponível mesmo quando a página de login é exibida e após o envio do formulário.

PUBLICAÇÃO
1. Substitua js/main-v62.js no frontend do Admin.
2. Publique também index.html para atualizar o cache-busting do JavaScript.
3. Mantenha checklist.html e js/checklist.js da versão de correção anterior, que já aceitam ?id=15.
4. Não precisa publicar o Worker nem executar migração D1 para esta alteração.
